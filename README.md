# VisTacAlign — project page

Anonymous project page for **VisTacAlign: Co-Training Dexterous Policies on Tactile Human
and Robot Demonstrations** (under review, ICRA 2027).

Served by GitHub Pages at https://vis-tac-align.github.io

- `index.html` — the whole site (single file, no build step, no external dependencies)
- `static/images/` — figures exported from the paper at 150 dpi

## Anonymity

This page must stay free of author names, institutions, lab names, funding
acknowledgements and links to personal or lab pages while the paper is under review.
